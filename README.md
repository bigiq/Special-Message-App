# Special Message App ✨

An interactive, personalized code generator designed to help you express your feelings in a unique and memorable way. Whether it's a proposal, an anniversary, or just a special note, this app creates a standalone interactive experience for your recipient.

## 🚀 Features

- **Personalized Content**: Custom titles and messages for a truly unique experience.
- **Background Soundtrack**: Integration with YouTube playlists to set the mood.
- **Interactive Reveal**: A final "Option 7" that links to a personal video message.
- **View Tracking**: Use your own YouTube video to know exactly when your message has been viewed.
- **Standalone Output**: Generates a single HTML file that works on any device without installation.

## 📁 Repository Structure

- `pc/`: Contains the Windows executable (`special.exe`) version of the builder.
- `screenshots/`: Visual guides on how to use the web and desktop applications.
- `docs/`: Promotional assets and detailed guides.

## 🛠️ How to Use

### 1. Access the Builder
You can use the [Web App](http://wasibahmed.pythonanywhere.com/login) or download the `special.exe` from the `pc/` folder.

### 2. Craft Your Message
- Enter the recipient's name.
- Provide a YouTube playlist link for the background music.
- Fill in 6 custom titles and messages (memories, questions, or notes).

### 3. The Final Reveal (Crucial Step)
The 7th option is the most important. 
- **Open a YouTube Channel**: If you don't have one, create it.
- **Upload a Video**: Record a personal message or use an AI-generated one.
- **Set as Unlisted**: Upload the video as "Unlisted" so only people with the link can see it.
- **Copy the Link**: Paste this link into the 7th option field in the builder.
- **Why?**: When your recipient clicks this option, your YouTube view count will increase, letting you know they've reached the end!

### 4. Share the Result
The builder will generate a `.html` file. Send this file to your special person via any messaging app or email. They just need to double-click to open it!
